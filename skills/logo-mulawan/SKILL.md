# لوكو ملون

صدّر لكل منصة صورة PNG مستقلة بمقاس 2400 × 1600 وخلفية مسطحة بلون `#1b1b1b`. اعتمد نقطة منتصف الرسم الظاهر في بطاقة ستيم عند **(1200، 590)**، وقِس منتصف كل شعار بعد قصّ فراغ المصدر. بهذا تصطف المراكز حتى عندما تختلف ارتفاعات الشعارات.

استخدم الرسم الأصلي بترتيب حروفه وعناصره وألوانه وتدرجاته. كبّره أو صغّره بالتناسب في الاتجاهين. يقارن المصيّر عدد بكسلات الرسم المرئية على الخلفية بمرجع ستيم المرفق، ويستهدف فارقاً بحدود ٣٪ عندما يسمح شكل الشعار. للشعار الطويل أو العريض جداً، اعتمد أقرب حجم يُبقيه كاملاً داخل البطاقة وبنفس المركز. مثال آرك رايدرز المعتمد محفوظ بمفتاح `arc-raiders`.

شغّل `npm ci --prefix "<skill>"` عند أول استخدام. استبدل `<skill>` بمجلد هذه المهارة. مثال لدسكورد:

```sh
node "<skill>/scripts/render.cjs" discord "<output>/discord.png"
```

مفاتيح الشعارات المرفقة هي `steam`، `arc-raiders`، `xbox`، `netflix`، `valorant`، `itunes`، `league-of-legends`، `discord`، `playstation` و`windows11`. يطبّق المصيّر قاعدة ستيم عند التصدير.

لمنصة جديدة، مرّر مسار ملف الشعار الأصلي بصيغة SVG أو PNG بخلفية شفافة مكان مفتاح المنصة. اختر رسماً متجهياً أو صورة نقطية تكفي دقتها للحجم الناتج. افتح الصورة بعد التصدير وقارن مركزها وحجم الرسم فيها ببطاقة ستيم.

في مشروع tlestore احفظ الصور في `output/g2-topup-icons/`. اعرض كل صورة منفردة وبترتيب الطلب.
